## 05 — ENGINEERING PRINCIPLES

| Principle | Standard |
|:--|:--|
| **Determinism** | Prefer reproducible state transitions and replayable research. |
| **Measurement** | Tie performance claims to explicit workloads and methodology. |
| **Mechanism** | Model liquidity, latency, execution, and risk rather than abstracting them away. |
| **Validation** | Test robustness beyond a single backtest or performance number. |
| **Simplicity** | Keep the critical path explicit, observable, and explainable. |
